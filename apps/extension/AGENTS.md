# ReLife extension (`apps/extension`): notes

Repo-wide rules and the layout map are in the root `AGENTS.md`. This is a Chrome MV3 extension in plain scripts:
no bundler, no runtime dependencies.

- Shared helpers are in `lib.js` (everything hangs off `self.RL`; the worker loads it with `importScripts`). Add a
  member to `ReLifeShared` in `globals.d.ts` when you add one.
- Type-check with `npm run typecheck -w apps/extension` (`checkJs`, not strict). Type server data with
  `import('@relife/contract')` in JSDoc; never import zod at runtime here.
- Storage is `chrome.storage.local` only, never `sync` (it would upload the token to Google). Add new keys to `Stored`
  in `globals.d.ts`.
- Colors come from `tokens.css` (generated; run `npm run tokens`, never edit it). `popup.css` only adds what is not a token.
- Icons are inline SVG strings in `icons.js`, generated by `npm run icons -w apps/extension`.
- The server side is `apps/web/src/core/companion.ts` and `apps/web/src/app/api/{activity,companion}`.
- Bump `manifest.json` (and `package.json`) with each change. `npm run pack -w apps/extension` builds the store zip.
