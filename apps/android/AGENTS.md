# ReLife Android app

A small Kotlin + Jetpack Compose app that reads Health Connect once an hour and sends daily summaries to a ReLife
server (`POST /api/v1/health`, plan: `.plans/v1-adoption.md` Phase 4 §E). It keeps no game rules: the server turns the
days into entries, XP and alerts. It pairs as kind `phone` with the `ingest` scope only, so a lost token can add health
numbers and nothing else. `applicationId com.relife.android`. Distribution is a signed APK on GitHub Releases (Play needs
a Health Connect declaration review).

## Layout (`app/src/main/java/com/relife/android/`)

- `api/` `Models.kt` (Kotlin twins of the `packages/contract` types it uses) and `Client.kt` (`HttpURLConnection`, no
  HTTP library). `ReLifeApi` is the interface tests fake.
- `pair/PairLink.kt` pure: reads the web page's QR (`https://host/pair#s=<secret>`) or the Mac link, normalizes typed
  addresses, says which hosts may use plain `http`.
- `health/Days.kt` pure: day windows in the server's time zone, sleep assigned to the wake date, awake stages removed,
  values clamped to the contract's ranges. `Reader.kt` is the only Health Connect code.
- `sync/SyncRunner.kt` one sync, no Android types (unit tested); `SyncWorker.kt` WorkManager glue (hourly, 15 minute flex,
  network required, exponential backoff, plus "Sync now" as expedited-style one-time work).
- `store/Prefs.kt` private SharedPreferences (the token lives here; `allowBackup=false` and the extraction rules keep it
  off backups). `ui/` Compose, `Theme.kt` fills Material3 from `Tokens.kt`.
- `ui/Tokens.kt` is generated by `packages/tokens/build.mjs`; do not edit it (`npm run tokens`, `-- --check` guards it).
  The launcher icon foreground is written by `packages/brand/build.mjs`; the app name is read from
  `packages/brand/brand.json` by `app/build.gradle.kts`. Do not type the product name in strings; use the `app_name`
  resource (`npm run brand:check` guards `.kt` only through its file list, so keep to this by hand).

## Build and check

JDK 17 and the Android SDK (platform 36, build-tools 36) are needed; set `sdk.dir` in `local.properties` (gitignored).

```
cd apps/android
./gradlew testDebugUnitTest lintDebug assembleDebug   # what CI runs on a PR
./gradlew assembleRelease                              # R8 on; signed with the debug key unless the env below is set
```

- Unit tests: `ContractTest` decodes the files in `packages/contract/fixtures` (Gradle sets the `contractFixtures`
  system property; there is no copy), plus `PairLinkTest`, `DaysTest` and `SyncRunnerTest`. When the contract changes,
  update `api/Models.kt` and the tests together.
- Health Connect itself can only be tried on a device or an emulator with Health Connect and its test data app.
- Gradle stays out of the pre-push hook; CI (`.github/workflows/android.yml`) runs it.

## Rules

- Read only. Never request a write permission, and never send anything but the `HealthBatch` the contract defines.
- A reading Health Connect did not have is an absent key, never `null` and never `0` (`explicitNulls = false`).
- A 401 means the device was revoked: forget the token and show the pair screen. Do not retry it.
- HTTPS is the default. A plain `http` address (LAN, Tailscale, `.local`) is allowed after the person confirms it.
- Keep the manifest's rationale activity and the `VIEW_PERMISSION_USAGE` alias: without them the permission sheet fails.

## Signing a release

Releases are built by CI on a `android-v*` tag from four repository secrets: `ANDROID_KEYSTORE_B64` (the keystore, base64),
`ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Make the keystore once and keep it safe:

```
keytool -genkeypair -v -keystore relife-release.jks -alias relife -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 relife-release.jks   # paste into the ANDROID_KEYSTORE_B64 secret (on macOS: base64 -i relife-release.jks)
```

The keystore must never change: Android refuses to update an app signed with a different key, so people would have to
uninstall and lose their pairing. Never commit it (`*.jks` and `*.keystore` are gitignored).
